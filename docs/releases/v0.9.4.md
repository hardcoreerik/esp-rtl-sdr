# esp-rtl-sdr 0.9.4

Adds experimental Nooelec SMArt XTR/E4000 bring-up, manual and tuner AUTO gain,
and opt-in hardware offset tuning. Initialization establishes a fixed low-gain
baseline before restoring the requested gain. In one controlled COM39 test,
the fixed-14 dB restart difference improved from ~1.85 dB to 0.088 dB.
Installed-device control reads are protected against disconnect races.

E4000 remains experimental. This is not all-band gain calibration or full
hardware qualification. A broader manual/AUTO serial test timed out and remains
an open investigation. Other profiles retain their existing qualification;
no fresh all-dongle RF run is claimed. Diagnostic startup tracing defaults OFF.
The component does not patch ESP-IDF; the historical HAL workaround is excluded.

Validation: focused profile test passed; 37,764 actual-function runtime checks
passed including disconnect-at-lock; CI covers Linux/Windows and IDF5.5.4/6.1.
Version 0.9.4 is explicitly selected by the maintainer for this pre-1.0 release.
